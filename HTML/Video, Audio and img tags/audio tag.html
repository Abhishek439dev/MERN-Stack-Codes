Audio Tag

The audio tag is used to embed audio in a web page. It is a semantic tag which means it provides meaning to the content it contains. It is used to play audio on a web page.
It's a block-level element and its attributes are almost similar to the video tag.

The audio tag has several attributes like src, controls, autoplay, loop, muted, preload, etc.

  • src: The src attribute is used to specify the path of the audio file.
  • controls: The controls attribute is used to display the audio controls.
  • autoplay: The autoplay attribute is used to play the audio automatically when the page loads.
  • loop: The loop attribute is used to play the audio in a loop.
  • muted: The muted attribute is used to mute the audio.
  • preload: The preload attribute is used to specify how the audio should be loaded when the page loads. It can be auto(loads the complete audio), metadata(loads only the audio metadata), or none(loads nothing).
