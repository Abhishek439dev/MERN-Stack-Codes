Video Tag

The video tag is used to embed a video in a web page. It is a semantic tag which means it provides meaning to the content it contains. It is used to display videos on a web page.

The video tag is a block-level element which means it will occupy the complete width of its parent element.

The video tag has several attributes like src, width, height, controls, autoplay, loop, muted, poster, preload, etc.

  • src: The src attribute is used to specify the path of the video file.
  • width: The width attribute is used to specify the width of the video player.
  • height: The height attribute is used to specify the height of the video player.
  • controls: The controls attribute is used to display the video controls.
  • autoplay: The autoplay attribute is used to play the video automatically when the page loads.
  • loop: The loop attribute is used to play the video in a loop.
  • muted: The muted attribute is used to mute the video.
  • poster: The poster attribute is used to specify an image to be displayed before the video starts playing.
  • preload: The preload attribute is used to specify how the video should be loaded when the page loads. It can be auto(loads the complete video), metadata(loads only the video metadata), or none(loads nothing).
