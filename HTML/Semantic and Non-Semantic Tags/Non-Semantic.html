Non-Semantic Tags:

Div Tag

Introduction: The div tag is a non-semantic tag which is used to group together the content. It does not provide any meaning to the content it contains. It is used for grouping, styling and layout purposes. div tag is a block-level element which means it will occupy the complete width of the parent element and will start on a new line just like, this div has started on a new line after the heading.
The elements after a div will also start on a new line. It can contain other block-level elements like headings, paragraphs, lists, etc. and inline elements like links, images, etc.

Span Tag

Introduction: The span tag is another non-semantic tag which is used to group together the content. It does not provide any meaning to the content it contains as well. It is used for grouping, styling and layout purposes. span tag is an inline element which means it will occupy only as much width as it needs and will not start on a new line.
The elements within a span stays in same line and will also not start on a new line. It can contain other inline elements like links, images, etc. but cannot contain block-level elements like headings, paragraphs, lists, etc.
This can be used to apply styles to a portion of text. This can also be used to group together inline elements for styling purposes like in a nav bar.
