This is an exercise involving the use of HTML and CSS to create a static LinkedIn post section.
It involves a number of elements which are required to align precisely so that, it feels equivalent to a real Linkedin post in appearance.

I have added images (of my own), SVGs, flavicon and other visual elements.
I have used flexbox and its properties to align the items properly in place.
