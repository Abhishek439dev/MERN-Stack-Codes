This is the div with box-styling set to content-box.

The content of this div occupies all the width which is set to this div. The properties like border, padding occupy extra pixels as specified and do not adjust into the specified width of 200px.
This result in increase of the overall width of the div (border + padding + content + padding + border).

This is the div with box-styling set to border-box.

The content of this div does not occupies all the width which is set to this div. The width of properties like border, padding adjust into the specified width of 200px.
The width of the div remains 200px because the content-width has adjusted with width of padding and border.
