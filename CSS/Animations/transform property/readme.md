This property can be used to move objects along X or Y or both the axis of a plane. : translateX, translateY or translate().
We can use it to rotate the objects at different angles. : rotate(45deg).
We can increase or decrease the size of the object in different directions. : scaleX, scaleY or scale().
We can alter the shape of the object. : skewX, skew Y or skew().
